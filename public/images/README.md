# Photos — Abdullah Raees Portfolio

Place Abdullah's real photos in this folder using the file names below.
The site tries these local files first, then falls back to the assets currently published
on the Canva portfolio / YouTube channel, and finally to a clean monogram placeholder.
No AI-generated faces are used anywhere.

| File                      | Used in                         | Recommended size / ratio      |
| ------------------------- | ------------------------------- | ----------------------------- |
| `abdullah-hero.jpg`       | Hero portrait                   | 1200 × 1500 px (4:5), portrait|
| `abdullah-about.jpg`      | About section                   | 1000 × 1250 px (4:5)          |
| `abdullah-avatar.jpg`     | Instagram / YouTube profile card| 600 × 600 px (1:1)            |
| `abdullah-mediakit.jpg`   | Media kit portrait              | 1200 × 1500 px (4:5)          |
| `instagram-profile.png`   | Instagram screenshot            | 1920 × 1080 px (16:9)         |
| `content-1.jpg` … `content-4.jpg` | Content previews & campaign visuals | 1080 × 1080 px (1:1) |
| `projects/reel-1.jpg` … `reel-3.jpg` | Portfolio reel covers | 1080 × 1350 px (4:5)        |
| `og-cover.jpg`            | Social sharing preview (Open Graph) | 1200 × 630 px             |

Tip: export JPGs at ~80 % quality to keep the site fast.
All paths are configured in `src/config/site.ts` (the `images` object).
